# Slint no_std Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Import the no_std-oriented `slint` crates.io dependency set into `external` with gnrt and validate that basic Slint public types can be referenced from the loader no_std test app.

**Architecture:** Add `slint` to the root Cargo manifest with default features disabled, let Cargo resolve the dependency graph, vendor resolved crates under `external/vendor/`, then generate GN metadata with the existing gnrt templates. Keep validation compile-only and limited to lightweight public types; do not enable rendering, platform, windowing, `.slint`, or `slint!` macro usage.

**Tech Stack:** Rust, Cargo, gnrt, GN `cargo_crate` templates, vendored crates under `external/vendor/`.

---

## File structure

- Modify: `Cargo.toml`
  - Owns the root `bluekernel_crates_io` dependency list consumed by Cargo and gnrt.
  - Add a `[dependencies.slint]` table with default features disabled.
- Modify: `Cargo.lock`
  - Records the resolved `slint` version and its transitive dependencies.
- Modify/Create: `vendor/slint-*/` and other new `vendor/*/` directories shown by `git status --short vendor`
  - Created by `target/gnrt-bin/gnrt vendor` for `slint` and any new transitive dependencies.
- Modify/Create: `vendor/slint-*/BUILD.gn` and other new `vendor/*/BUILD.gn` files shown by `git status --short vendor`
  - Generated by `target/gnrt-bin/gnrt gen` for new crates.
- Modify/Create: `vendor/slint-*/README.blueos` and other new `vendor/*/README.blueos` files shown by `git status --short vendor`
  - Generated by `target/gnrt-bin/gnrt vendor` for new crates.
- Modify if required: `gnrt_config.toml`
  - Add only crate-specific license or build-script metadata required to make gnrt generation succeed.
- Inspect/optionally modify for validation: `/home/chenyinhua/blueos-dev/kernel/loader/tests/inputs/no_std_app/src/main.rs`
  - Add a compile-only basic Slint type usage only if external import succeeds and the kernel tree expects this validation to be committed with the import.
